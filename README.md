# Saad Shaikh: Inside Modern Data Systems

Source for [saad-shaikh14.github.io/Saad-Shaikh-Analytics-Portfolio](https://saad-shaikh14.github.io/Saad-Shaikh-Analytics-Portfolio/). It is a personal publication on data engineering, data platform architecture and AI: reference architectures drawn from cited documentation, and a writing section for long-form articles.

Built with Astro and TypeScript, written in Markdown and MDX, and deployed to GitHub Pages by GitHub Actions.

| Guide | What it covers |
|---|---|
| [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md) | Visual direction, colour, typography, layout, components, diagram style |
| [docs/VISUAL_VERIFICATION.md](docs/VISUAL_VERIFICATION.md) | The source-first process every published figure goes through |
| [docs/EDITORIAL_GUIDE.md](docs/EDITORIAL_GUIDE.md) | Voice, accuracy rules, claim classes, article structure |
| [docs/PUBLISHING_GUIDE.md](docs/PUBLISHING_GUIDE.md) | Adding an article, preview, checks, Substack and LinkedIn versions |
| [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) | Build, CI, GitHub Pages, legacy URLs, cutover and rollback |
| [docs/QA_REPORT.md](docs/QA_REPORT.md) | Results of the release checks |

```sh
npm ci && npm run dev
```
